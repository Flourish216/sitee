Prototype Workflow
I first sketched out interaction ideas in the p5 Web Editor. https://editor.p5js.org/Jeesez/collections/MPUMzPEa- Once these basic prototypes were working, I ask LLM to help me refine the visuals and build more richer versions for the final site. My process was to first describe the desired effect and constraints, then have the LLM generate a more advanced version of the code. I reviewed each generated block and integrated it only after I fully understood how it worked.
